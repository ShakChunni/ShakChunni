## Current research

- **Post-quantum TLS for MQTT.** I measure how packet loss, latency, and bandwidth limits affect connection setup and message delivery in IoT and edge networks.
- **Post-quantum certificate migration.** I study what happens to existing connections and resumed TLS sessions when an MQTT broker switches to a post-quantum certificate.
- **Phishing detection.** I evaluate how email detectors hold up when phishing messages are rewritten.
